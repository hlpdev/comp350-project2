# comp350-project2

Simple shell using ``execvp``.
Append `` &`` to the end of a command to run in the background.
Does not support quotations in commands.

### Building
```
git clone https://github.com/hlpdev/comp350-project2.git
cd comp350-project2
```
requires `gcc`
```
chmod +x ./build.sh
./build.sh
```

### Usage
```
./build/osh
```

### Cleanup
```
chmod +x ./clean.sh
./clean.sh
```
